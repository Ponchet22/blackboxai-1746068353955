# BlockPuzzle Game

## Project Overview
BlockPuzzle is a simple and interactive puzzle game where players can place various shapes on a grid to score points. The objective is to strategically fit the available blocks on the board, clear rows and columns, and achieve the highest score possible. This game combines elements of strategic placement and spatial reasoning.

## Installation
To run the BlockPuzzle game locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd blockpuzzle
   ```

2. **Open the `index.html` file**:
   You can simply open the `index.html` file in your web browser to start playing the game.

## Usage
Once the game has loaded in your browser, you can start by choosing a block shape from the available options. Click on the grid to place the selected block. As you place blocks, you can clear full rows and columns to score points. Use the "Reset" button to start a new game anytime.

## Features
- **Interactive Game Board**: A 10x10 grid to place blocks on.
- **Multiple Block Shapes**: Various shapes available for selection, including single, double, and L-shaped blocks.
- **Scoring System**: Earn points for each block placed and for clearing rows and columns.
- **Reset Functionality**: Easily reset the game to start over at any time.

## Dependencies
This project does not rely on any external libraries other than the following, which are included in the `index.html`:

- **Tailwind CSS**: For styling the game interface. 
- **Font Awesome**: For icons (not specifically utilized in the current implementation but included in the header).
